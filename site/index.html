Notebook entries

  1. Robot using free spin of bearings to calculate motion · Notebook — Using a free-spinning bearing as a motion sensor: s = 2πrN, friction decay Iω̇ = −τ_f, and a predict-then-correct residual.
  2. Bell State: Quantum vs. Classical Simulation · Notebook — Can a classical computer be modeled from a Bell state? Bell states, no-signaling, and a CHSH calculation reaching |S| = 2√2.
  3. C Bisection Algorithm Header File · Notebook — A bisection root finder in C: sign-change check, interval halving, stopping rules, and status codes.
  4. Circle Plot with 0.1 Rad Step · Notebook — Sampling the parametric unit circle x = cos θ, y = sin θ at a 0.1 rad step, in Python.
  5. Drift Rate: Definition, Calculation, Applications · Notebook — Drift rate across fields: the μ in dY = μ dt + σ dW, biased random walks, drift-diffusion models, and electron drift velocity.
  6. Invent New Calculus · Notebook — An invented 'Fold Calculus' built on sequences of crests and troughs: fold derivative, fold integral, a fundamental theorem, a worked example, and a coding loop.
  7. Half-Integer Program Concept · Notebook — The "1/10 int" idea: a ten-register integer machine with ten integer ops, plus slots reserved in memory for boot files. Almost no formulas. Captured as-is.
  8. Identity Matrix in Linear Algebra · Notebook — The 3×3 identity matrix and its properties: IA = AI = A, det I = 1, I⁻¹ = I, eigenvalues all 1.
  9. Linear Algebra Yields Interactive Sprites · Notebook — How vectors and (homogeneous) transform matrices drive sprites in real-time graphics. Qualitative, no equations.
  10. Logarithms and Exponents Exploration · Notebook — Reading handwritten notes on the definition u = logₙ v ⇔ nᵘ = v, with examples like log₆₀ 60 = 1.
  11. Dark matter equals 1xc/d =b+1c/d · Notebook — Rearranging DM = xc/d = b + c/d into closed forms for b, x and d, then substituting the invariant d = 2xc − 1.
  12. Fibonacci Sequence Clone with Diode Alterations · Notebook — Applying 2xc − d = 1 to a piece of text, then a Fibonacci sequence with every term halved (0.5, 0.5, 1, 1.5, 2.5, …) and a one-way "diode" gate in a demo matcher that uses only fictional profiles.
  13. FMC' 1D Formula Derivation · Notebook — Reading the fragment Fmc' 1d = f, *c = d − 1, c = f as a small system alongside 2xc − d = 1, and when the two expressions for d can agree.
  14. 2xc - d Metric for All Computing · Notebook — The chat that sets up the metric: 2xc − d = 1 is declared the "metric for all computing" and solved for d, x and c, then wrapped as a sandbox program template and a speech-to-text "valuation engine".
  15. X Metric Equation Solved · Notebook — Several ways to parse X=b-1c/dxcd=1/2c-1 as algebra, and the slice where two readings agree: c = 1/4, d = 4/x, X = b − x/16.
  16. Decoding Physics and Quantum Equations · Notebook — Interpreting H = xz² − x/m as a qubit or anharmonic-oscillator Hamiltonian, a QuTiP simulation, and printing circuits in a terminal.
  17. STEM Student Physics Notebook Analysis · Notebook — Turning a physics notebook page into a SymPy program: v = 2πr/T, vector magnitude, and KE/PE/momentum placeholders.
  18. π² Einstein energy-mass relation · Notebook — A units check of the proposed π² = E·m − c, and dimensionally consistent rearrangements involving E = mc².
  19. Solving Quadratic Equation Step-by-Step · Notebook — Solving x² − x/v = mc with the quadratic formula, then a look at what changes if c is the speed of light (including a units check).
  20. Standard Deviation Calculation Explanation · Notebook — Reading 100/9.65² as the variance of a sample mean (σ²/n), standard error, CEP, and a Python Monte Carlo check.
  21. Circumference of 3/2 Circle · Notebook — Distance = (3/2)πr: the arc length of a 270° path.
  22. u p i ternary system · Notebook — A three-letter 'binary-like' system with digits u, p, i: first as base 3, then a custom mapping, plus a binary converter.
