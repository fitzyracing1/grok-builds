## Notebook entries

- [Robot using free spin of bearings to calculate motion · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/bearing-odometry.html): Using a free-spinning bearing as a motion sensor: s = 2πrN, friction decay Iω̇ = −τ_f, and a predict-then-correct residual.
- [Bell State: Quantum vs. Classical Simulation · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/bell-states-chsh.html): Can a classical computer be modeled from a Bell state? Bell states, no-signaling, and a CHSH calculation reaching |S| = 2√2.
- [C Bisection Algorithm Header File · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/bisection-c.html): A bisection root finder in C: sign-change check, interval halving, stopping rules, and status codes.
- [Circle Plot with 0.1 Rad Step · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/circle-plot.html): Sampling the parametric unit circle x = cos θ, y = sin θ at a 0.1 rad step, in Python.
- [Drift Rate: Definition, Calculation, Applications · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/drift-rate.html): Drift rate across fields: the μ in dY = μ dt + σ dW, biased random walks, drift-diffusion models, and electron drift velocity.
- [Invent New Calculus · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/fold-calculus.html): An invented 'Fold Calculus' built on sequences of crests and troughs: fold derivative, fold integral, a fundamental theorem, a worked example, and a coding loop.
- [Half-Integer Program Concept · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/half-integer-program.html): The "1/10 int" idea: a ten-register integer machine with ten integer ops, plus slots reserved in memory for boot files. Almost no formulas. Captured as-is.
- [Identity Matrix in Linear Algebra · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/identity-matrix.html): The 3×3 identity matrix and its properties: IA = AI = A, det I = 1, I⁻¹ = I, eigenvalues all 1.
- [Linear Algebra Yields Interactive Sprites · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/linear-algebra-sprites.html): How vectors and (homogeneous) transform matrices drive sprites in real-time graphics. Qualitative, no equations.
- [Logarithms and Exponents Exploration · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/logarithms-exponents.html): Reading handwritten notes on the definition u = logₙ v ⇔ nᵘ = v, with examples like log₆₀ 60 = 1.
- [Dark matter equals 1xc/d =b+1c/d · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/metric-dark-matter.html): Rearranging DM = xc/d = b + c/d into closed forms for b, x and d, then substituting the invariant d = 2xc − 1.
- [Fibonacci Sequence Clone with Diode Alterations · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/metric-fibonacci-diode.html): Applying 2xc − d = 1 to a piece of text, then a Fibonacci sequence with every term halved (0.5, 0.5, 1, 1.5, 2.5, …) and a one-way "diode" gate in a demo matcher that uses only fictional profiles.
- [FMC' 1D Formula Derivation · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/metric-fmc-1d.html): Reading the fragment Fmc' 1d = f, *c = d − 1, c = f as a small system alongside 2xc − d = 1, and when the two expressions for d can agree.
- [2xc - d Metric for All Computing · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/metric-for-all-computing.html): The chat that sets up the metric: 2xc − d = 1 is declared the "metric for all computing" and solved for d, x and c, then wrapped as a sandbox program template and a speech-to-text "valuation engine".
- [X Metric Equation Solved · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/metric-x-equation.html): Several ways to parse X=b-1c/dxcd=1/2c-1 as algebra, and the slice where two readings agree: c = 1/4, d = 4/x, X = b − x/16.
- [Decoding Physics and Quantum Equations · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/nonlinear-hamiltonian.html): Interpreting H = xz² − x/m as a qubit or anharmonic-oscillator Hamiltonian, a QuTiP simulation, and printing circuits in a terminal.
- [STEM Student Physics Notebook Analysis · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/physics-notebook-program.html): Turning a physics notebook page into a SymPy program: v = 2πr/T, vector magnitude, and KE/PE/momentum placeholders.
- [π² Einstein energy-mass relation · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/pi-squared-energy-mass.html): A units check of the proposed π² = E·m − c, and dimensionally consistent rearrangements involving E = mc².
- [Solving Quadratic Equation Step-by-Step · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/quadratic-mc.html): Solving x² − x/v = mc with the quadratic formula, then a look at what changes if c is the speed of light (including a units check).
- [Standard Deviation Calculation Explanation · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/standard-error.html): Reading 100/9.65² as the variance of a sample mean (σ²/n), standard error, CEP, and a Python Monte Carlo check.
- [Circumference of 3/2 Circle · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/three-halves-circle.html): Distance = (3/2)πr: the arc length of a 270° path.
- [u p i ternary system · Notebook](https://fitzyracing1.github.io/grok-builds/notebook/site/upi-ternary.html): A three-letter 'binary-like' system with digits u, p, i: first as base 3, then a custom mapping, plus a binary converter.

## How it works

`build_site.py` renders each project README (pandoc) and copies the Notebook's pre-rendered KaTeX pages into `site/`, which `.github/workflows/pages.yml` deploys to GitHub Pages. MIT licensed.
